# Day03 CNN 实验四人分工计划表

> 本项目（7 个 CNN 案例实验）按四人小组协作完成。分工对齐实际开发流程：
> **环境与数据 → 网络实现 → 训练调优 → 验收文档**四条工作线，成员各有主责、
> 交叉复核，避免单人瓶颈与重复劳动。

## 一、成员与角色

| 成员 | 角色 | 主责模块 | 交叉复核 |
|---|---|---|---|
| 成员 A | 环境负责人 + 实验1/4 | 环境、数据管道、入门实验 | 实验5 代码评审 |
| 成员 B | 网络实现主力 | 实验2、实验3（AlexNet） | 实验6 代码评审 |
| 成员 C | 训练调优主力 | 实验5、实验6（车牌） | 实验2 代码评审 |
| 成员 D | 验收与文档负责人 | 实验7、汇总文档 | 实验3 代码评审 + 全部结果复核 |

## 二、任务分解（对齐实际开发流程）

### 阶段 0：环境与数据基线（成员 A 主责，全员确认）

| 任务 | 说明 | 产出 |
|---|---|---|
| A1 统一开发环境 | Python 3.12 专用 venv + TensorFlow 2.21 CPU（Python 3.14 不支持 TF，禁止用主环境） | `.venv`、README 环境说明 |
| A2 公开数据集管道 | MNIST / CIFAR-10 / Olivetti 三套数据的下载与离线缓存（镜像源下载、格式转换脚本） | `build_cifar_cache.py`、`build_olivetti_cache.py` |
| A3 私有数据集接入规范 | fer2013 / bird_photos / licence_plate / bca_data 的目录约定与 `--synthetic` 合成验证开关 | README 数据放置表 |
| A4 Git 规范 | .gitignore 屏蔽大模型与数据缓存；commit 信息规范 | `.gitignore` |

### 阶段 1：基础分类实验（成员 A/B 主责）

| 任务 | 说明 | 产出 |

### 阶段 2：进阶应用实验（成员 B/C 主责）

| C1 实验6 车牌识别 | 文件名标签 text2vec one-hot 编码 + 多标签输出层（Reshape+Softmax）+ vec2text 还原 | `06-plate/` |

### 阶段 3：医学图像与全流程验收（成员 C/D 主责）

## 三、时间安排（建议 2 天）

## 四、协作约定

1. **分支/提交**：各任务完成后即 commit（小步提交），信息格式 `实验N 实验名：一句话结果`；
   大模型文件（.keras >100MB）与数据集不入库，仅保留 result.txt 与图片。
2. **代码责任**：谁的目录谁负责复跑通过；评审人发现问题提回作者修改。
3. **进度同步**：每天结束对齐一次：已完成实验、卡点（数据/环境）、次日计划。
4. **私有数据**：4 个课程数据集到位后按 README 放入 datasets/，去 `--synthetic`
   重跑并把结果更新进 SUMMARY（责任人：对应实验作者，复核：D）。
