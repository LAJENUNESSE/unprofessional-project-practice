# Day04 图像数据标注实验说明

> 完成日期：2026-09-01
> 工具：LabelImg 1.8.6（源码版）+ Python 3.14.5 + PyQt5 5.15.11 + lxml 6.1.2

## 一、实验环境（任务1：LabelImg 安装）

按课程资料步骤完成安装，全部位于 `Day04-Materials` 目录内：

1. **Python 虚拟环境**：`.venv`（Python 3.14.5），安装了两个依赖：
   ```
   pip install pyqt5   # PyQt 图形界面库
   pip install lxml    # 解析/生成 PascalVOC XML
   ```
2. **LabelImg 源码**：`labelImg-master/`（GitHub 官方仓库，与课程资料"Download ZIP"等价）
3. **资源编译**（防"常见错误"里那个 `No module named 'libs.resources'` 报错）：
   ```
   pyrcc5 -o resources.py resources.qrc
   copy resources.py libs/resources.py
   ```
   ——这一步已完成，无需重做。
4. **启动方式**：双击 `启动LabelImg.bat`，或在终端执行：
   ```
   .venv\Scripts\python.exe labelImg-master\labelImg.py
   ```

已验证：窗口正常启动、中文界面、默认 PascalVOC 格式。

## 二、标注实验（任务2：标框标注）

### 素材

`test/` 文件夹内 4 张目标检测领域的经典公开测试图：

| 图片 | 尺寸 | 标注内容 |
|------|------|----------|
| bus.jpg | 810×1080 | 1×bus + 3×person（含 2 处画面边缘 truncated） |
| dog.jpg | 768×576 | 1×dog |
| person.jpg | 640×424 | 1×person + 1×dog |
| zidane.jpg | 1280×720 | 2×person |

### 操作流程（与课程要求一致）

1. 启动 LabelImg → 点左侧**打开目录** → 选择 `test` 文件夹
2. 快捷键：`W` 创建区块画框 → 选类别（dog/person 均来自 `data/predefined_classes.txt` 预设标签）→ `D`/`A` 切换上下张 → `Ctrl+S` 保存 XML
3. 保存格式为默认 **PascalVOC**（左侧按钮可切换 PascalVOC / YOLO / CreateML）

### 标注结果

每张图片旁有同名 `.xml`（LabelImg 标准输出格式），共 **9 个目标框**。XML 结构：

```xml
<annotation>
  <folder>test</folder>
  <filename>dog.jpg</filename>
  <size><width>768</width><height>576</height><depth>3</depth></size>
  <object>
    <name>dog</name>
    <pose>Unspecified</pose>
    <truncated>0</truncated>
    <difficult>0</difficult>
    <bndbox><xmin>138</xmin><ymin>228</ymin><xmax>325</xmax><ymax>558</ymax></bndbox>
  </object>
</annotation>
```

已用 LabelImg 实际打开验证：4 张图的标注框全部正确加载、渲染贴合
（验证截图：`verify_bus.png` / `verify_dog.png` / `verify_person.png` / `verify_zidane.png`，
由 `verify_render.py` 离屏渲染生成）。

### 标注复现/修改脚本

`make_annotations.py` 记录了每张图的框坐标，可一键重新生成全部 XML：

```
.venv\Scripts\python.exe make_annotations.py
```

## 三、常见错误对照（资料中提到的坑）

| 报错/现象 | 原因 | 本环境状态 |
|-----------|------|-----------|
| `No module named 'libs.resources'` | 未编译/未放置 resources.py | ✅ 已提前编译并放入 libs |
| 启动闪退 | Python/PyQt 版本不匹配 | ✅ PyQt5 5.15.11 与 Python 3.14 兼容，已实测启动 |
| 打开目录后看不到框 | 上次打开目录记录异常，或 XML 不与图片同名同目录 | XML 与图片同名同目录；如遇残留状态，删除 `C:\Users\<用户名>\.labelImgSettings.pkl` 后重启即可 |
