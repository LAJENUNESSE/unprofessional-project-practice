## 1. 软件概述

CSV 数据清洗报表工具是一款**单机桌面应用**，面向没有编程背景的数据使用者（学生、运营、行政等），解决日常拿到 CSV 文件时的四类高频问题：

1. **打不开 / 打开乱码** —— 中文 CSV 常见 UTF-8 与 GBK 编码混杂，本工具自动识别
2. **数据脏** —— 缺失值、重复行、首尾空格、`¥1,299.00` 式文本数字、异常数值
3. **看不清** —— 想快速看分布、占比、相关性，不想写代码画图
4. **说不清** —— 做了哪些清洗操作，事后无法向他人交代

对应地，工具提供 **数据体检 → 清洗操作 → 统计图表 → 导出报告** 的完整闭环，并且**每一个清洗动作自动记录日志**，导出的报告自动携带全部操作记录，保证结果可追溯。

核心特性一览：

- 纯绿色单文件 exe，**无需安装 Python**，双击即用
- UTF-8 / GBK 编码自动识别，坏行自动跳过兜底
- 四种缺失值策略、两种 IQR 异常值策略、货币文本转数值、混合格式日期解析
- 四种统计图表内嵌窗口，中文界面中文图表
- 一键导出 Excel 友好的 CSV（带 BOM）与 Markdown 分析报告
- 清洗日志全记录，支持课堂/工作汇报场景的"过程留痕"

## 2. 获取与安装

### 2.1 方式一：直接运行 exe（推荐，零安装）

**系统要求**：Windows 10 / 11 64 位。

**步骤**：

1. 拷贝 `dist/CsvCleaner.exe` 到任意目录（桌面、U 盘均可，单文件 55MB）
2. 双击运行

**必知的三件事**：

- **首次启动需等待 3~5 秒**：单文件模式每次启动要先解压运行时到临时目录，属正常现象，不是卡死。之后操作不卡。
- **杀毒软件可能误报**：PyInstaller 打包的未签名 exe 是杀软误报高发区。若被拦截，选择"仍要运行 / 加入信任"；企业电脑无权限时改用方式二。
- **临时目录**：解压发生在系统临时目录（`%TEMP%`），退出程序后自动清理，不会在 U 盘留垃圾。

### 2.2 方式二：从源码运行

**系统要求**：Python ≥ 3.12（本项目在 3.14.5 开发验证）。

项目已附带建好的虚拟环境 `.venv/`（含全部依赖），**优先直接复用**：

```bash
cd C:\Dev\Workspace\Unprofessi_nal_project_practice\csv-cleaner

# 复用现有环境（日常）
.venv\Scripts\python.exe -m csv_cleaner

# 或以可编辑方式安装后用命令启动
.venv\Scripts\python.exe -m pip install -e .
csv-cleaner
```

如果 `.venv` 丢失或损坏，重建：

```bash
cd C:\Dev\Workspace\Unprofessi_nal_project_practice\csv-cleaner
python -m venv .venv
.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -e .[dev]
```

> 说明：`-i` 指定清华镜像源，直连 PyPI 在本机网络下经常超时；`[dev]` 会一并安装 pytest 与 PyInstaller。

### 2.3 重新打包 exe（需要修改代码后）

```bash
.venv\Scripts\python.exe -m PyInstaller --onefile --windowed --noconfirm ^
    --name CsvCleaner --paths src launcher.py
```

产物输出到 `dist/CsvCleaner.exe`。`--windowed` 隐藏黑色控制台；`--onefile` 打成单文件。

## 5. 功能详解

### 5.1 打开文件与编码识别

**入口**：菜单 文件 → 打开 CSV…（快捷键 `Ctrl+O`）。

**工作方式**：

1. 读取文件前 200KB 字节，用 chardet 库探测编码
2. GB2312 / GBK / GB18030 探测结果统一按 `gbk` 解码（GBK 是 GB2312 的超集，覆盖更全）
3. 分隔符自动嗅探（`,``;``\t` 等）；个别行字段数异常时跳过坏行并继续，保证尽量打开文件

**注意**：

- 目前支持 **CSV 文本格式**；`.xlsx` 暂不支持（规划中的扩展项）
- 编码识别结果显示在状态栏，如 `（编码 gbk）`
- 探测只读前 200KB，极少数前段纯英文、后段中文的文件可能误判，此时改用源码方式指定编码打开

### 5.2 数据体检（发现问题）

**入口**：① 分区"重新体检"按钮；打开文件和每次清洗后也会自动执行。

**指标含义**：

| 指标 | 判定规则 |
| --- | --- |
| 类型 | 数值列（dtype 为数字）／日期列（抽样 50 个非空值，80% 以上可解析为日期）／文本列（其余） |
| 缺失 / 缺失率 | 空单元格计数与占该列比例 |
| 唯一值 | 该列去重后的取值个数（判断"ID 列 vs 类别列"的参考） |
| 异常值 | 仅数值列：IQR 法，低于 `Q1 − 1.5×IQR` 或高于 `Q3 + 1.5×IQR` 的个数 |
| 备注"文本列含数值，可转换" | 文本列去掉货币符号（`¥ $ € £`）、千分位逗号和空格后，60% 以上能转成数值——提示你去做类型转换 |

**用法建议**：体检结果是从上到下执行清洗的"任务清单"，备注列写了"可转换"的列优先去 ④ 做类型转换。

### 5.3 行级清洗（② 分区）

| 按钮 | 行为 | 注意 |
| --- | --- | --- |
| 去除完全重复行 | 只有**整行每个字段都相同**才算重复，保留第一次出现的行 | 订单号不同但其他字段相同的不算重复（合理设计，避免误删真实业务） |
| 文本列去首尾空格 | 对所有文本列执行 `"  北京 "` → `"北京"` | 只去首尾，中间空格不动；数字列不受影响 |
| 删除含缺失值的行 | 删除任意列有缺失的行 | 破坏性最强的一键操作，**删多少行看日志**；只想按某一列删时改用下面的填充策略 |

### 5.4 缺失值填充（③ 分区）

**操作**：列下拉框选列 → 策略下拉框选策略 →（固定值策略需在输入框填写内容）→ 点"填充所选列"。

| 策略 | 填充值 | 适用场景 |
| --- | --- | --- |
| `mean(均值)` | 该列数值均值 | 数值列、分布近似对称、无严重异常值时 |
| `median(中位数)` | 该列数值中位数 | 数值列、存在异常值或偏态分布时（**推荐默认**，稳健） |
| `mode(众数)` | 出现次数最多的值 | 文本/类别列（如城市、类别） |
| `constant(固定值)` | 你输入的值 | 有业务含义的占位，如"未知"、0 |

**边界行为（重要）**：

- **均值/中位数只对数值列有效**。对纯文本列选均值/中位数，工具计算出的统计量为空，**相当于不填充**（不会报错也不会污染数据）；文本列请用众数或固定值
- 对没有缺失的列执行填充是合法空操作，日志会记"无缺失，跳过"
- 填充针对**整列所有缺失**，无法只填某几行（如需精确控制，先删行再填充）

### 5.5 类型转换（④ 分区）

**数值转换**（把"看起来是数字"的文本列真正转成数字）：

- 自动清理：货币符号 `¥ $ € £`、千分位逗号（`1,299.00`）、首尾空格
- **转换失败的单元格保留为缺失值**（不会填 0，也不会中断）——例如列里混了"三十五"这种文字，它变回空值等待你用缺失值策略处理
- 日志记录成功转换的单元格数

**日期转换**：

- 支持混合格式同列解析：`2025-01-15`、`2025/1/16` 可共存于一列
- 无法解析的值同样保留为缺失

**何时需要转换**：体检备注列出现"文本列含数值，可转换"时；不转换该列无法参与直方图、箱线图、热力图和均值/中位数填充。

### 5.6 异常值处理（⑤ 分区）

**判定**：IQR 四分位法。`下界 = Q1 − 1.5×IQR`，`上界 = Q3 + 1.5×IQR`，界外即异常。

| 方式 | 行为 | 何时选 |
| --- | --- | --- |
| `clip(缩进边界)`（默认） | 界外值改为边界值（如 220 → 64.9） | 想保留样本量；测量型误差数据。**注意边界是数学值，可能出现小数** |
| `remove(删除行)` | 整行删除 | 异常明显是录入错误且数量少 |

**设计说明**：体检阶段只"报告"异常值个数，不做任何修改；只有你在这个分区点了按钮才会处理。列没有异常值时为空操作并记日志。

### 5.7 列管理（⑥ 分区）

- **删除所选列**：整列删除，用于无分析价值的 ID、备注列
- 重命名功能以"删除所选列 + 重新打开"方式替代（当前版本未提供重命名界面入口，接口已实现，规划下版加入）

### 5.8 统计图表（图表页签）

**操作**：选列（下拉框）→ 选图表类型 → 点"绘制"。

| 图表 | 需要选列 | 适用 |
| --- | --- | --- |
| 直方图 | 数值列 | 看分布形态（清洗前后对比效果直观） |
| 箱线图 | 数值列 | 看中位数、四分位与离群点（圆点即异常值） |
| 柱状图(频次TOP10) | 任意列 | 看类别占比（取频次最高的前 10 项） |
| 相关性热力图 | **不用选** | 看所有数值列两两相关系数（-1~1），数值列不足 2 列时不可用 |

**注意**：

- 直方图/箱线图选中的列若转数值后全为空，会提示"没有可绘图的数值"而不崩溃
- 热力图每格标注相关系数，红=正相关、蓝=负相关
- 中文标签已内置字体配置，无需额外设置；若导出图片需求，下版支持右键保存

### 5.9 导出

| 菜单项 | 产物 | 细节 |
| --- | --- | --- |
| 导出清洗后 CSV… | 当前数据全量 | **UTF-8 带 BOM**（`utf-8-sig`）：Excel 双击打开中文不乱码；列顺序与当前一致 |
| 导出分析报告 (Markdown)… | 一份 `.md` 文件 | 自动包含四章：① 清洗前体检结果 ② 清洗操作记录（全部日志表格）③ 清洗后统计摘要（数值描述 + 各类别列 TOP5）④ 数据预览前 20 行 |

报告是标准 Markdown，可用 Typora / VSCode / 语雀等直接渲染，也可贴进 Word。

### 5.10 清洗日志（可追溯性核心）

- 每个清洗动作产生一条记录：`步骤号 / 操作名 / 参数说明 / 影响行数`
- 例：`5. [处理异常值] 列「客户年龄」缩进 1 个异常值到 [1.88, 64.88] (影响1)`
- 日志按顺序累计，**只增不减**（当前版本无撤销功能，见第 7 节）；"重新体检"类查看操作不产生日志
- 导出报告时日志完整写入第二章

## 6. 典型场景配方（Cookbook）

### 场景 A：清洗平台导出的销售 / 库存表

> 特征：货币符号列、千分位、末尾空格、少量缺失

推荐序列：体检 → 去重 → 去空格 → 货币列转数值 → 关键列缺失填中位数 → 类别列缺失填众数 → 异常值 clip → 导出报告。

### 场景 B：问卷 / 成绩表

> 特征：年龄/分数列有手滑极端值，文本列有"未填写"

推荐序列：体检 → 去重（重复提交）→ 分数列转数值 → 年龄异常值 **remove**（手滑值不可信）→ "未填写"列用固定值填充 → 箱线图复查分布 → 导出。

### 场景 C：设备 / 日志指标数据

> 特征：无重复概念，重点是异常剔除

推荐序列：打开 → 体检看异常值计数 → 数值列 clip 缩进 → 直方图确认分布恢复 → 导出 CSV 供后续分析。

## 7. 已知限制（使用前必读）

1. **没有撤销功能**：清洗只前滚不回滚。误操作的正确姿势是重新打开原文件再走一遍（全程一键操作，重做成本低）。养成"先体检、小步操作、勤看日志"的习惯
2. **不支持 `.xlsx`**：请先在 Excel 里"另存为 CSV"
3. **预览有显示截断**：超 200 行只显示前 200 行、浮点显示 4 位有效数字——都不影响底层处理与导出结果
4. **界面语言与数据编码**：界面为简体中文；`utf-8-sig` 导出文件在极老版本 Excel（2007 以前）可能仍需手动选编码
5. **单文件 exe 启动慢**：每次启动解压 3~5 秒，对 U 盘部署场景更明显；介意可改用 `--onedir` 模式打包（改一个参数）
6. **重名列**：打开的 CSV 若本身有重复列名，pandas 会自动加后缀区分（`列名.1`），建议先重命名数据源

## 8. 故障排查（症状 → 原因 → 解决）

| 症状 | 可能原因 | 解决 |
| --- | --- | --- |
| 双击 exe 没反应 | 首次解压中 | 等 3~5 秒；再等仍无窗口 → 见下条 |
| 杀毒软件弹窗拦截 | PyInstaller 未签名误报 | "仍要运行"或加白名单；或改用源码运行 |
| 打开文件后中文乱码 | 编码探测误判（罕见） | 换源码运行方式指定编码；或确认文件本身未损坏 |
| 图表页画不出来 | 未选列 / 所选列转数值后全空 / 数值列不足 2 列（热力图） | 按提示换列；先做类型转换 |
| 均值/中位数填充后没变化 | 目标列是纯文本列（统计量为空） | 文本列改用众数或固定值；或先转数值 |
| 界面里数字位数变少 | 预览 4 位有效数字显示截断 | 正常现象，导出数据完整 |
| 找不到某列 | 该列被删除列操作移除 | 查看清洗日志确认；重新打开原文件 |
| 导出报告打不开 | Markdown 需渲染器 | 用 VSCode / Typora 打开，或复制进 Word |

### 9.3 术语表

| 术语 | 解释 |
| --- | --- |
| IQR | 四分位距，`Q3 − Q1`；IQR 法以上下界之外判定异常值，不依赖正态分布假设 |
| 中位数 | 有序数据中间位置的值；受极端值影响小，适合填缺失 |
| 众数 | 出现频率最高的值，适合类别数据 |
| BOM | 字节顺序标记；UTF-8 文件带 BOM 时 Excel 能正确识别编码 |
| clip | 缩进/截断：把越界值替换为最近的边界值 |
| 可追溯性 | 所有清洗步骤留有记录，结果可以复核与复现 |
