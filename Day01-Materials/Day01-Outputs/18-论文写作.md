# 一、摘要（约300字）

> **摘要**：去中心化交易所（DEX）作为去中心化金融（DeFi）生态的核心基础设施，依托自动做市商（AMM）机制重构了传统金融的交易范式，其市场影响力日益凸显。本文以Uniswap、Curve等主流DEX为研究对象，基于2020—2024年以太坊链上交易数据，构建面板回归与事件研究模型，实证考察DEX交易活动对加密资产市场质量的影响。研究发现：第一，DEX流动性深度显著提升资产价格发现效率，且该效应在长尾资产中更为突出；第二，DEX与中心化交易所（CEX）之间存在双向价格引导关系，在极端行情下DEX的价格领先性明显增强；第三，AMM机制下的滑点成本与无常损失抑制流动性供给，加剧了价格波动。本文的研究拓展了数字资产市场微观结构理论，为DeFi协议优化与金融监管政策制定提供了经验证据与决策参考。
>
> **关键词**：去中心化交易所；自动做市商；价格发现；市场质量；DeFi

# 三、自我评价与改进建议

**优点：**
1. **逻辑闭环完整**：遵循“提出问题—理论机制—研究设计—实证检验—结论建议”的实证范式，符合学术规范；
2. **摘要与提纲对应紧密**：摘要中的三个核心发现（价格发现、跨市场引导、成本约束）在提纲中均有承接章节；
3. **实证要素齐全**：包含稳健性、内生性、异质性检验，达到高质量实证论文的基本要求。

**不足与改进建议：**

1. **识别策略需前置强化（最重要）**：DEX交易量与市场质量存在双向因果，仅靠工具变量说服力有限。建议利用外生冲击构建准自然实验，如以太坊合并（The Merge）、FTX崩盘事件、Uniswap V2→V3协议升级，采用DID或断点回归设计，这是当前审稿人最看重的部分。

2. **章节偏多，建议压缩**：7章结构更适合博士论文；若为硕士论文或期刊投稿，建议将第6章并入第5章，形成6章结构，避免内容碎片化。

3. **摘要存在“预设结论”风险**：当前摘要中的实证发现是为搭建框架而预设的，实际写作中必须以真实回归结果为准修正摘要，切勿“结论先行”。

4. **变量度量需进一步细化**：“市场质量”是多维概念，建议在第4章明确各维度的代理变量（如买卖价差、Amihud非流动性指标、已实现波动率、Hasbrouck信息份额等）。

5. **数据可行性应说明**：链上数据清洗复杂度高，建议明确数据接口（Dune Analytics、The Graph等）及代币样本筛选标准，这也是答辩中常被追问的问题。

总体而言，该提纲框架成熟、方向可行，重点在于**补强因果识别策略**并**根据实际数据情况收敛研究范围**。需要我帮你细化某一章节（如假设推导或模型设定）吗？
