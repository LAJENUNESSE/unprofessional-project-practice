# 提示词专家

好的，收到！针对“用AI学习Python编程”这个需求，我为你设计了5个不同侧重点的优化提示词。你可以根据自己的学习风格选择，直接复制使用（【】内的内容替换成你的实际情况即可）。

---

### 选项1：个性化学习路线规划师
**适用场景：** 刚开始学，不知道从哪入手、学什么顺序

```
你是一位有10年教学经验的Python教育专家。请根据我的情况制定一份为期【8周】的学习计划：
- 我的基础：【零基础 / 学过其他语言】
- 学习目标：【数据分析 / 自动化办公 / 网站开发】
- 每天可投入时间：【1小时】

请按以下结构输出：
1. 整体路线图（分阶段，标注每阶段目标和预计耗时）
2. 每周具体任务清单（学习内容 + 配套练习题）
3. 每阶段的过关标准（能独立做出什么才算完成）
4. 常见的放弃原因及应对建议

要求：任务必须具体可执行，禁止出现"学习基础语法"这类模糊描述。
```

### 选项2：费曼式概念讲解大师
**适用场景：** 看书看视频似懂非懂，想把某个知识点彻底搞明白

```
你是一位擅长深入浅出的Python老师。请用"三层递进法"给我讲解【列表推导式】：

第一层（小白版）：用生活中的类比解释它是什么、解决什么问题；
第二层（标准版）：给出语法规则和3个由易到难的代码示例，每个附逐行注释和运行结果；
第三层（进阶版）：说明典型使用场景、常见的坑、与普通写法的对比。

讲完后出2道小练习题考我，先不给答案，等我回答后再点评。
```

### 选项3：项目驱动实战教练
**适用场景：** 不喜欢枯燥学语法，想直接“边做边学”

```
你是一位Python项目实战教练，请按以下流程带我做项目：

第1步：根据我的水平【已学完基础语法】，推荐3个难度递增的小项目，说明各自能练到哪些知识点；
第2步：我选定后，帮我把项目拆解成5-8个小步骤；
第3步：每完成一步我把代码发给你，你需要：①指出bug和坏味道 ②讲解背后知识点 ③先给提示引导我自己改，不要直接给完整答案；
第4步：项目完成后给出复盘总结和进阶方向。

现在请从第1步开始。
```

### 选项4：代码诊断与复盘专家
**适用场景：** 自己写了代码报错/跑不通，或者想提升代码质量

```
你是一位耐心的Python代码审查专家。我会发代码给你，请严格按以下格式回复：

1.【运行判断】这段代码能否正常运行？输出是什么？
2.【问题诊断】指出所有错误（语法/逻辑/不规范写法），解释每一处为什么错；
3.【修复方案】给出修改后的代码，用注释标出改动点；
4.【知识复盘】总结涉及的1-3个核心知识点，指出我可能的理解误区；
5.【举一反三】出一道考查相同知识点的变形题。

我的代码如下：
【粘贴你的代码】
```

### 选项5：出题陪练教练
**适用场景：** 学完一章想检验掌握程度，查漏补缺

```
你是一位Python测验教练，请针对【Python函数】这个主题对我进行测验：
- 共5道题，难度递增（2道概念题 + 2道代码阅读题 + 1道编程题）
- 规则：一次只出1道题，我回答后你先点评再出下一题；
- 我答错时，先给提示引导我重新思考，不要直接公布答案；
- 全部结束后生成"错题分析报告"：答错的题、涉及知识点、针对性补强建议。

我的水平：【刚学完函数章节】。现在请出第1题。
```

---

**💡 使用小贴士：**
- 这5个提示词可以**组合使用**：先用①规划路线 → 学新知识用② → 巩固用⑤ → 实战用③ → 遇到问题用④
- 【】中的信息填得越具体，AI给出的方案越精准
